# db link E-M1 Mark II migration handoff

This handoff preserves the successful E-M1 Mark II USB-tethering diagnostic for the Teclast T60Pro (Android 15). Start with BASELINE.md and ACCEPTANCE.md; the project is an experimental fork of db link, not an upstream production release.

On the replacement PC, clone the fork, check out the exact commit in BASELINE.md, and obtain the private evidence archive separately. Do not use moving branch names as a substitute for verifying the commit. The working application and production photography workflow must not be replaced without a separate decision.

The GitHub Actions APK artifact may expire; preserve the supplied private archive and verify its checksums. Original logs and captures may contain image data and private information: keep them private.
